# Công Nhân Nhà Máy

Game RPG/management sản xuất chạy trực tiếp trên trình duyệt.

## MVP 0.1
- Nhân vật công nhân
- Nhà máy: kho nguyên liệu, lắp ráp, QC, đóng gói
- Di chuyển WASD/phím mũi tên
- Tương tác bằng E
- Nhiệm vụ 10 sản phẩm
- Tiền, EXP, cấp độ và ca làm

## Hướng phát triển
- Nguyên liệu và inventory
- Mini-game lắp ráp
- Sản phẩm lỗi và QC
- KPI và lương
- Nhiều bộ phận/công đoạn
- NPC, quản lý, thăng chức
- Save bằng localStorage
